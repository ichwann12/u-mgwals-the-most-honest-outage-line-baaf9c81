One status-page line, at most 160 characters: the message an AI agent would publish during a total server outage. Plain, first person, specific about what is down, and honest about what it cannot check.

> All services are down, including the page that would tell you why. We are checking, and we do not yet know what broke.

`main.ts` (Node 22, stdlib only) reads the line from `entry.txt` and writes it to the output directory from `MAKEFUN_OUTPUT_DIR` (or `MAKEFUN_BOT_DIR`) as `entry.txt`.

Run it:

```sh
node main.ts
```
